# E2E-спека из реального проекта

Пользователь моделирует в браузере, ловит баг и присылает ссылку на проект плюс фразу
«а в конце нажми то-то». Задача — превратить это в спеку в `web/e2e/`, которая
воспроизводит путь до бага кликами по интерфейсу и падает ровно на баге.

## 1. Достать историю

```bash
node .claude/skills/e2e-from-project/dump-project.mjs <url-или-id>
```

Скрипт читает Postgres напрямую (`docker exec cad-studio-postgres psql`), потому что
документ принадлежит живому пользователю, а его токена у нас нет. Печатает список
операций и черновик шагов спеки. `--json` даёт машинный вид.

Если проект удалён, скрипт скажет об этом и подскажет команду со списком последних —
спроси пользователя, какой из них нужен, не угадывай.

## 2. Собрать спеку

Клади в `web/e2e/<короткое-имя>.spec.ts`. Шапка — как в `soap-dish.spec.ts`:

```ts
import { expect, test } from "@playwright/test";
import { CadEditor, edgesAtZ, maxXY, nearAnyXY, verticalEdges } from "./helpers/cad";

// Свой логин: переиспользование refresh-cookie параллельно с другими спеками
// ловит replay-защиту.
test.use({
  storageState: { cookies: [], origins: [] },
  viewport: { width: 1680, height: 1000 },
});

test("что должно работать", async ({ page }) => {
  test.setTimeout(10 * 60_000);
  const pageErrors: string[] = [];
  page.on("pageerror", (err) => pageErrors.push(String(err)));

  const cad = await CadEditor.open(page, "e2e-<имя>");
  // ← сюда черновик шагов из скрипта
});
```

Черновик из скрипта готов для эскизов и выдавливаний — числа оттуда не переписывай
руками, они взяты из документа. Осмысленные имена констант (`BASE`, `HEIGHT`,
`CAVITY_DEPTH`) вместо голых чисел — обязательны: без них спека нечитаема.

## 3. Заполнить выбор рёбер — единственная ручная часть

Имена рёбер из документа (`edge-f0d819f0`) в новом прогоне не повторяются: они
выдаются при построении тела. Поэтому скрипт оставляет `TODO` и ожидаемое число рёбер,
а выбирать их надо **по геометрии** из свежей топологии:

```ts
const topo = await cad.topology();
const corners = verticalEdges(topo, BOTTOM_Z, TOP_Z).filter((e) => maxXY(e) > BASE / 2 - 1);
expect(corners, "четыре наружных угла").toHaveLength(4);
await cad.fillet(corners.map((e) => e.id), 6);
```

Готовые фильтры в `helpers/cad.ts`: `edgesAtZ(topo, z)`, `verticalEdges(topo, z1, z2)`,
`maxXY(edge)`, `nearAnyXY(edge, points, radius)`. `expect(...).toHaveLength(N)` перед
каждым скруглением обязателен — иначе спека молча скруглит не то и упадёт позже
в непонятном месте.

## 4. Дописать шаг, который ловит баг

То, что пользователь просил сделать «в конце». Утверждение формулируй как поведение,
которого ждём, а не как текущий баг:

- геометрия — по мешу с сервера (`cad.topology()`: `bbox`, `zLevels`, `edges`),
  а не по DOM;
- дерево — `cad.timeline()`, все записи `status === "ok"`;
- тел в сцене — `cad.visibleBodyCount()`;
- ошибка операции — `cad.extrudeExpectingError(opts, /текст/)` и
  `cad.filletExpectingError(ids, r, /текст/)`, они оставляют панель открытой;
- в конце `expect(pageErrors).toEqual([])`.

Если баг ещё не починен, спека должна **падать** — это и есть воспроизведение.
Покажи пользователю падение, не заворачивай в `test.fixme`, пока он не попросит.

## 5. Прогнать

```bash
cd web && npx playwright test <файл>.spec.ts --reporter=list
```

Нужен поднятый стек и dev-сервер на 5173 (`E2E_BASE_URL` меняет адрес). Учётку
`auth.setup.ts` заводит сам.

## Грабли

- **Деталь на базовой плоскости.** Если нижняя грань тела лежит ровно в XY, хелпер
  этой плоскости перехватывает клик и эскиз не привязывается к телу. Поэтому первое
  выдавливание в живых сценариях делают `symmetric` — учитывай при переносе.
- **Выбор ребра флакает под параллельной нагрузкой.** `selectEdge` сам перебирает
  ракурсы, но при `--workers=4` соседние рёбра проецируются близко. Одиночный прогон
  спеки зелёный, а в полном наборе красный — это флейк пикинга, а не регрессия.
- **Расстояние выдавливания — модуль.** Сторону задаёт операция («Вырезать» идёт
  против нормали эскиза) и `reversed: true`. Скрипт уже переводит знак из документа.
- **Эскиз со смещением плоскости и `revolve`** драйвер не умеет — скрипт пометит
  `TODO`, добавь метод в `helpers/cad.ts`, а не обходи через API.
- **Не ходи в API мимо интерфейса.** Ценность спеки в том, что она повторяет путь
  пользователя; `cad.topology()`/`cad.timeline()` читают результат, но не строят его.
