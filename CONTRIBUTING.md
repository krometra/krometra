Проект распространяется под [FSL-1.1-ALv2](./LICENSE.md) (Functional Source License с переходом в Apache-2.0 через два года).

2. Вы предоставляете автору проекта неисключительное, бессрочное, безотзывное право использовать, изменять и перелицензировать ваш вклад, включая коммерческое лицензирование и будущие смены лицензии проекта.
3. Вклад является вашей собственной работой и не нарушает прав третьих лиц.

FSL — source-available лицензия, а не open source в смысле OSI: код можно читать, менять и использовать, в том числе внутри компании, но нельзя строить на нём конкурирующий продукт; каждая версия через два года переходит в Apache-2.0. Передача прав на вклад — стандартная практика для таких проектов (аналогично Sentry): без единого правообладателя проект не сможет исполнять обещание этого перехода.

## Как начать

Требования и команды — в [`README.md`](./README.md) (быстрый старт) и [`CLAUDE.md`](./CLAUDE.md) (конвенции кода). Архитектурные принципы — в [`AGENTS.md`](./AGENTS.md).

```bash
cp .env.example .env
make up && make migrate      # PostgreSQL + Redis + MinIO + backend + собранный фронт
make frontend-shell          # Vite dev-сервер на :5173
```

## Перед отправкой PR

- `cd web && npm run build && npm run lint` — зелёные, без новых warnings.
- `cd web && npm test` — vitest зелёный (включая тесты операций ядра на OCCT/WASM).
- `cd backend && pytest` — тесты backend зелёные.
- Новая геометрическая операция без юнит-тестов не принимается (см. AGENTS.md, раздел «Геометрическое ядро»). Геометрия считается только в браузерном ядре (`web/src/workers/`), серверного fallback нет.
- Мутирующая операция обязана сразу отражаться во вьюпорте без перезагрузки страницы.
- Для заметных изменений редактора желательна e2e-спека (`web/e2e/`, образец — `soap-dish.spec.ts`).

Приоритеты и открытые задачи — в [`.docs/ROADMAP.md`](./.docs/ROADMAP.md). Хорошие первые задачи помечаются в Issues меткой `good first issue`.

## Сообщения об ошибках

Создайте Issue по шаблону «Баг» с шагами воспроизведения. Для багов геометрии приложите последовательность операций (эскиз → фичи) или ссылку на экспортированный STEP.
